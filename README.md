# Этап «Процессы» (idea-graph-processes)

Роли → сценарии → выбор для автоматизации → «как есть» (с болями) → вид автоматизации → «как будет».

| Шаг | Что создаётся |
|---|---|
| Роли | Карточки «роль» (каждая выбранная — отдельная), предложения берутся из банка анализа конкурентов |
| Сценарии | Карточки «сценарий»; роли-участницы — связи «участвует» (на холсте они скрыты, у сценария виден список ролей); диаграмма вариантов использования строится из графа |
| Выбор | Поле «Автоматизировать: да/нет/позже» (+ важность, частота) на карточке сценария; шаг утверждается, когда выбран хотя бы один |
| Как есть | Карточка «как есть» с диаграммой последовательности: шаги «кто → кому: что», боли на шагах (что не так, как часто, чем стоит, важность) |
| Решение | Карточка «решение» (виды автоматизации по шагам или ролям) и «как будет» — диаграмма с «Системой», «БД», внешними ресурсами и отметками отличий |

**Диаграммы** хранятся структурой в `attrs.diagram`; рисует их `static/sequence.js`, правка — таблица шагов или вставка текста
(«Кто → Кому: что», знаки `+ ~ * -` для отличий, `[боль: …]`). Экспорт в Mermaid — `diagrams.to_mermaid`.

Помощник на каждом шаге: предложить, проверить (независимый ревьюер), уточнить (неточности вроде роли, которой не было, превращаются в
вопросы с вариантами), сгенерировать. Автоматический режим проходит шаги по очереди; на развилках решает совет, обоснование
(2–3 фразы) записывается в карточку.
